Updated September 2026 • 5 min read • By E-Commerce Logistics Guide

Official Flipkart Order PDF Dimensions

By default, Flipkart Seller Hub issues orders as an A4 page with the following dimensions:

  • Page Width: 210 mm (8.27 inches / 595.28 PDF points)
  • Page Height: 297 mm (11.69 inches / 841.89 PDF points)

Exact Shipping Label Box Dimensions

The shipping courier label (top half) is enclosed within a solid black border. Its exact measurements are:

Why You Need Native Vector Cropping

Many free tools convert PDFs to low-resolution JPEG images. When an image is resized, the sharp black-and-white stripes of the Code128 / EAN barcode become blurred around the edges. When the Ekart or Delhivery courier pickup agent tries to scan the label using their handheld scanner, it fails to decode.
