Amazon Easy Ship Label Size & Thermal Printer Settings Guide (100x150mm / 4x6)

Updated September 2026 • 8 min read • By QuickCrop Technical Hardware Team

Quick Reference Specs:

Standard Dimension: 100 mm × 150 mm (or 4.00 × 6.00 inches) • Resolution: 203 DPI (812 × 1218 px) or 300 DPI (1200 × 1800 px) • Target PDF Points: 288 pt × 432 pt • Media: Direct Thermal Top-Coated Roll Paper.

Amazon Easy Ship Dimension Specifications

When Amazon India generates an Easy Ship label, it formats it within an A4 sheet. To print this label correctly on a desktop thermal barcode printer, you must map the extracted label boundary onto standard 4x6" label roll stock.

Thermal Printer Driver Configuration by Brand

1. TSC Printers (DA210, DA220, TE244)

TSC thermal printers are the most popular choice among Indian Amazon sellers. Here are the optimal driver settings:

  • Stock (Page Setup): Name a custom stock "Amazon 4x6" with Width 100 mm and Height 150 mm.
  • Sensor Type: Set to Die-Cut Labels with Gaps (Gap height: 3.0 mm).
  • Print Darkness: Set between 8 and 10. Do not set to 15 (max), as excess heat causes thin barcode white gaps to fill with ink.
  • Print Speed: 3.0 in/sec or 4.0 in/sec.

2. TVS Printers (LP 46 Neo, LP 44)

TVS Electronics thermal printers are widespread in logistics hubs across India:

  • In Windows Printers & Scanners, open Printing Preferences > Page Setup.
  • Set Media Type to Thermal Transfer with Gap or Direct Thermal.
  • Set Darkness to 9 and Dither to None (vector passthrough).

3. Xprinter (XP-420B, XP-470B)

For Xprinter models using Seagull Scientific drivers:

  • Select 4.00 in × 6.00 in stock.
  • Under Graphics tab, set Dithering to None to ensure Code128 barcodes remain pure black lines without grey pixel dither.

4. Zebra Printers (ZD220, ZD230, GK420d)

In ZDesigner Driver preferences:

  • Media Settings > Media Type: Thermal Direct.
  • Label Tracking: Web Sensing (Gap).
  • Darkness: 14–16 (Zebra scale 0–30).

How to Fix the "Blank Label Feeding" Error

A common complaint among Amazon sellers is: "My printer prints 1 label and then ejects 1 blank label!"

This happens when:

  1. Length Mismatch: The driver is set to 148mm or 152mm while your physical paper is 150mm. The driver thinks the content spilled onto page 2.
  2. Sensor Calibration Needed: Hold down the FEED button on your printer until the LED flashes red/orange, then release. The printer will measure 2 labels and calibrate the gap sensor.
  3. Cropping with QuickCrop: Always use QuickCrop's Amazon Easy Ship Cropper, which strictly enforces a 288 × 432 pt boundary with safe 4pt inner margins, completely eliminating page spillover.
