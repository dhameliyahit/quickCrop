Thermal Barcode Printer Setup for Amazon Labels

Safe, standard printing configuration for Indian e-commerce sellers using 4×6 thermal printers (TSC, TVS, Xprinter, Zebra):

Printer Compatibility Standard Media Size Margins Scaling & Layout Barcode Calibration
TSC TE244 / TE200 100mm × 150mm (4×6") 0 mm (Zero Margins) 100% / Actual Size Calibrate per manufacturer guide; preserve quiet zones
TVS LP 46 Neo 100mm × 150mm (4×6") 0 mm (Zero Margins) 100% / Actual Size Calibrate per manufacturer guide; preserve quiet zones
Xprinter XP-420B 100mm × 150mm (4×6") 0 mm (Zero Margins) 100% / Actual Size Calibrate per manufacturer guide; preserve quiet zones
Zebra ZD220 / ZD230 100mm × 150mm (4×6") 0 mm (Zero Margins) 100% / Actual Size Calibrate per manufacturer guide; preserve quiet zones

Safe Printing Checklist:

  • Media Size: Always set your thermal roll label size to 100×150 mm (4×6 inches) in your printer driver preferences.
  • Scale: Select "Actual Size" (100%) in your print dialog. Avoid "Fit to Printable Area", which distorts barcode line ratios.
  • Calibration: Run the manufacturer's auto-gap sensor calibration whenever loading a fresh roll of labels.
  • Quiet Zones: Ensure there is clean white space on both the left and right sides of the barcode to help ATSPL scanners read the parcel smoothly.

Frequently Asked Questions

Everything you need to know about cropping, stamping, and printing Amazon Easy Ship labels:

Why does Amazon generate labels and invoices on the same A4 sheet?
Amazon's default print layout was originally designed for standard office inkjet or laser printers using full A4 sheets. However, modern e-commerce sellers use dedicated 4×6 thermal roll printers to save money and dispatch faster. QuickCrop isolates only the shipping label, removes the tax invoice, and reformats the vector page into standard 4×6 inches without wasting paper or toner.
How does the automatic SKU & Quantity stamping work?
QuickCrop reads the tax invoice description line on the right side of the sheet, identifies the Seller SKU (e.g., from ( Fruit basket )) and the order quantity (e.g. Qty 1), and neatly stamps Fruit basket | Qty - 1 into the designated white space above the delivery station code on the thermal sticker. You can toggle this on or off anytime using the checkbox.

Can QuickCrop process multi-order Amazon PDFs with 2 orders per page?
Yes! QuickCrop automatically scans each A4 page and splits both the top order and bottom order into individual 4×6 thermal labels. A 10-page A4 document with 20 orders becomes a clean, 20-page 4×6 thermal PDF ready for your thermal printer roll.
Can I separate and download Amazon tax invoices into a separate PDF?
Yes! Click "Download Separate Invoices (PDF)" to extract all tax invoices from the right side of the sheet into a clean, dedicated PDF. You can keep this PDF for your monthly GST books or print customer invoices on standard A4 paper.
Will ATSPL and courier pickup associates be able to scan cropped barcodes?
Yes! QuickCrop uses pure vector Form XObject embedding rather than blurry bitmap screenshots. Every Code128 bar, 2D QR code, delivery station code, and AWB number retains 100% vector sharpness so courier pickup associates and hub scanners can scan parcels instantly on the first pass.
What thermal printer settings should I use for Amazon labels?
In your thermal printer driver (TSC TE244/TE200, TVS LP 46 Neo, Zebra ZD220, Xprinter XP-420B), set media paper size to 100mm × 150mm (or 4.00 × 6.00 inches) with 0 mm margins. In the print dialog, ensure Scale is set to "Actual Size (100%)" and margins are set to None. Avoid "Fit to Page" which shrinks barcodes.
Is my customer data and Amazon account information secure?
100% private and secure! All PDF processing, cropping, and SKU extraction happens entirely within your web browser using client-side JavaScript. No PDF files, customer addresses, phone numbers, or invoice amounts are ever sent to any remote server.
